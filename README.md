# 📌 Project Overview

EcoGuard is an Android-based Smart Waste Management and Environmental Monitoring application developed using Kotlin in Android Studio.

The project is designed to support smart-city development by improving waste collection efficiency, monitoring environmental conditions, and promoting sustainable urban management using AI and IoT concepts.

EcoGuard provides:
- Smart waste-bin monitoring
- Real-time waste status tracking
- Environmental monitoring
- Dashboard visualization
- Smart city map integration
- Sensor-based waste-level simulation

The application demonstrates how mobile technology can be integrated with environmental sustainability solutions.
